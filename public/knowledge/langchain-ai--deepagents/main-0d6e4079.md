## 建议阅读路线

1. 从 README 确认项目边界，依据官方文档运行最小示例。
2. 从包清单定位公开入口，对照上面的核心文件查找调用关系。
3. 选择一次最小任务，记录输入、状态、工具或存储调用以及输出。
